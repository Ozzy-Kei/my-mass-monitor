# Health Care

A Streamlit application for recording and visualizing health data.

## Features
* Record daily health measurements
* Store data using SQLite
* Visualize weight changes with charts
* Select a user and view their measurement history

## Technologies
* Python
* Streamlit
* SQLite
* pandas
* matplotlib

## Installation

Clone this repository and install the required packages:

```bash
pip install -r requirements.txt
```

## Usage

Run the Streamlit application:

```bash
streamlit run app.py
```

Then open the URL displayed in your terminal.

## Database

The application uses SQLite to store health data.

The database file (`health_care.db`) is not included in this repository. It is created automatically when the application runs.
